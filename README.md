# Hospital Readmissions

## Overview
This repository contains a project aimed at analyzing hospital readmissions and understanding the factors that contribute to them. The goal is to derive insights that can help in reducing readmission rates.

## Features
- Data analysis on hospital readmissions
- Visualization of key insights
- Extensive documentation

## Prerequisites
- Python 3.x
- pandas
- matplotlib
- seaborn
- Tableau

## Installation
1. Clone the repository:
   ```
   git clone https://github.com/<your-username>/Hospital-Readmissions.git
   cd Hospital-Readmissions
   ```
2. Install the required Python packages:
   ```
   pip install -r requirements.txt
   ```

## Database Setup
- To set up the database, import the provided CSV files into your database management system (e.g., MySQL, PostgreSQL):
  - `Patients.csv`
  - `Admissions.csv`
  - `Diagnoses.csv`

## Tableau Setup
1. Open Tableau.
2. Connect to your database.
3. Load the `Patients`, `Admissions`, and `Diagnoses` tables.

## Usage
- Run the analysis scripts in the `src` directory.
- Visualize the results using Tableau.
